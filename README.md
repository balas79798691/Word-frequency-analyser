# Word-frequency-analyser
🔤 Word Frequency Analyzer using Python

📌 Project Overview

This project analyzes a piece of text and identifies the most frequently occurring words.

It is a simple Natural Language Processing (NLP) project that demonstrates text preprocessing and word frequency analysis.

🎯 Objective

To count the occurrences of words in a given text and identify the most frequently used words.

🛠️ Technologies Used

- Python
- Google Colab
- Regular Expressions
- Collections Library
- Natural Language Processing (NLP)

⚙️ How It Works

1. The user enters a piece of text.
2. The text is converted to lowercase.
3. Words are extracted from the text.
4. Common stop words are removed.
5. The frequency of each remaining word is calculated.
6. The top 10 most frequently used words are displayed.

🚀 How to Run

1. Open Google Colab.
2. Upload "Word_Frequency_Analyzer.ipynb".
3. Run the cells.
4. Enter a paragraph or sentence.
5. View the word frequency results.

💻 Example

Input:

Python is easy to learn. Python is powerful and Python is popular.
